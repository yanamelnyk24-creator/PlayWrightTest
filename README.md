Практична робота з автоматизованого тестування сайту кінотеатру MovieLand за допомогою Playwright.
Інструменти
• JavaScript
• Node.js
• Playwright
Що перевіряє тест
1. Успішне відкриття сторінки.
2. HTTP-статус відповіді 200.
3. Наявність movieland в URL.
4. Наявність вмісту на сторінці.
Запуск тесту
npx playwright test cinema.spec.js —headed
Результат
Тест успішно виконано: 1 passed.
